# EdmCrack600

## Overview

EdmCrack600 is a task-specific package derived from the published EdmCrack600 crack segmentation dataset.

- Task: segmentation
- Images: 600
- Annotations: 1648
- Classes: 1 (crack)
- Annotation format: paired PNG masks

The source dataset includes 600 pavement images captured on roads in Edmonton, Canada, with pixel-level crack annotations.
